# Учебная виртуальная машина (УВМ)

Ассемблер и интерпретатор для учебной виртуальной машины.

## Архитектура УВМ

- **Размер команды**: 4 байта
- **Память**: объединенная (команды и данные), 1 МБ
- **Стек**: используется для передачи операндов
- **Формат команд**: младшие 7 бит - код операции (A), остальные биты - поле B

## Поддерживаемые команды

### 1. LOAD_CONST (A=43)
Загрузка константы на стек.
